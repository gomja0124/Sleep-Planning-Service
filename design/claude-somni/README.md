# Somni Claude Design export

This folder contains the original Claude Design export for the Somni sleep companion app.

- `Somni.dc.html` is the main interactive design source.
- `ios-frame.jsx` and `support.js` are required by the Claude Design runtime.
- `assets/` contains the final cropped Cat, Bat, and Owl expressions used by the prototype.

The design source explicitly targets an iPhone 17 Pro viewport (`402 × 874`). It is kept separate from the production web prototype so its Claude Design components and runtime helpers remain intact.
